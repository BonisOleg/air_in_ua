# Climatic

Веб-сайт компанії з продажу та встановлення кондиціонерів.

## Основні розділи:

*   Каталог кондиціонерів з фільтрами та можливістю покупки.
*   Перелік послуг з монтажу та обслуговування.
*   Форма зворотного зв'язку.
*   Адмін-панель для керування товарами та замовленнями.

## Технології:

*   Python
*   Django
*   HTML, CSS, JavaScript
*   SQLite (за замовчуванням)
